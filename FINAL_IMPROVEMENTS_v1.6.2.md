## 🧪 Тестирование

1. **Перезапустите серверы:**
```bash
# Terminal 1 - API
cd apps/api && pnpm dev

# Terminal 2 - Web
cd apps/web && pnpm dev
```

2. **Откройте браузер:** http://localhost:3000

3. **Проверьте header:**
   - Должна быть фиолетовая кнопка "✨ Апгрейд"

4. **Откройте Settings → Billing:**
   - Текущий план показывает статус вместо кнопки
   - Есть история подписок ниже
   - Кнопка "Продлить план" в истории
