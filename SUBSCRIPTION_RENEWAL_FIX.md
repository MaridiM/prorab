# Исправление продления подписки v1.6.2

## 🐛 Проблема

При попытке продлить текущий план (нажать на кнопку "Выбрать план" для уже активного плана) возникала ошибка:

```
❌ Не удалось создать подписку. Попробуйте снова.
```

**Причина:** 
Логика в `handleSelectPlan` проверяла, совпадает ли выбранный план с текущим:
```typescript
if (subscription.planId === planId) {
  toast('Вы уже используете этот план', 'info')
  return  // ❌ Блокировала продление!
}
```

Это блокировало возможность продлить тот же план (renewal).

---

## ✅ Решение

Изменена логика в `handleSelectPlan`:

### Было:
```typescript
if (subscription) {
  // Блокировка если тот же план
  if (subscription.planId === planId) {
    toast('Вы уже используете этот план', 'info')
    return  // ❌ Ошибка!
  }
  
  // Изменение плана
  const result = await changePlan({...})
  subscriptionId = result.data?.changePlan?.id
}
```

### Стало:
```typescript
if (subscription) {
  // Если другой план - изменяем
  if (subscription.planId !== planId) {
    const result = await changePlan({
      variables: {
        input: {
          subscriptionId: subscription.id,
          newPlanId: planId,
          immediate: false,
        },
      },
    })
    subscriptionId = result.data?.changePlan?.id
  }
  // Если тот же план - продление (subscriptionId остается прежним)
}
```

## 🎯 Как это работает

### Сценарий 1: Продление текущего плана (Renewal)
1. Пользователь на плане LITE
2. Нажимает "Выбрать план" на карточке LITE
3. `subscription.planId === planId` → TRUE
4. **Пропускаем** `changePlan()` 
5. Используем существующий `subscriptionId`
6. Вызываем `initializePayment(subscriptionId)` → создается новый платеж
7. Пользователь оплачивает → подписка продлевается

### Сценарий 2: Изменение плана (Change Plan)
1. Пользователь на плане LITE
2. Нажимает "Выбрать план" на карточке FOREMAN
3. `subscription.planId !== planId` → TRUE
4. **Вызываем** `changePlan(newPlanId: FOREMAN)`
5. Получаем новый/обновленный `subscriptionId`
6. Вызываем `initializePayment(subscriptionId)` → создается платеж
7. Пользователь оплачивает → план меняется на FOREMAN

### Сценарий 3: Новая подписка (New Subscription)
1. У пользователя нет подписки
2. Нажимает "Выбрать план" на любой карточке
3. `subscription === null` → FALSE
4. **Вызываем** `createSubscription(planId, teamId)`
5. Получаем `subscriptionId`
6. Вызываем `initializePayment(subscriptionId)`
7. Пользователь оплачивает → создается подписка

## 🔧 Backend поддержка

Backend автоматически определяет:
- **Renewal (Продление)**: Если подписка существует и plan не изменился
  - Создает новый Payment record
  - Обновляет `currentPeriodEnd` после успешной оплаты
  
- **Change (Смена плана)**: Если вызван `changePlan` mutation
  - Обновляет `plan` и `planId` в Subscription
  - Создает новый Payment record
  - Обновляет даты и лимиты
