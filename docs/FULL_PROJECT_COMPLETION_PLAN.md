## 🔄 ТЕКУЩИЙ ЭТАП: Этап 6 - Финансы и Зарплата (Finances & Payouts)
**Статус:** ✅ ВЫПОЛНЕН (Backend + Frontend)
**Приоритет:** 🔴 Критический

### Цель
Дать прорабу возможность рассчитывать и фиксировать выплаты бригаде. Избавить от блокнотов и конфликтов по деньгам.

### План реализации Frontend (Осталось сделать)

#### 1. Frontend Foundation (День 1)
- [x] **GraphQL Operations**:
    - Создать `payouts.graphql` (Queries: `PayoutSummary`, `ProjectPayouts`, `MemberPayouts`; Mutations: `UpdateMemberSalary`, `CreatePayout`, `CloseProject`).
    - [x] Использованы inline gql для надежности.
- [x] **Validation (Zod)**:
    - `member-salary.schema.ts` (валидация типа зарплаты и суммы/процента).
    - `payout.schema.ts` (валидация самих выплат).

#### 2. UI Компоненты (День 2)
- [x] **`MemberSalaryBadge`**: Отображает тип зарплаты (Фикс/Процент/Нет) в списках.
- [x] **`SalarySettingsForm`**: Модальное окно для настройки зарплаты конкретного участника (выбор типа, ввод суммы).
- [x] **`PayoutCalculator`**: "Умный" калькулятор.
    - Показывает: Бюджет, Расходы, Чистую прибыль.
    - Таблица выплат: Кто сколько получает + Статус выплаты.
    - Итоговая прибыль владельца.
- [x] **`PayoutHistoryList`**: История всех транзакций по проекту.

#### 3. Интеграция Страниц (День 3)
- [x] **Страница Команды (`/teams/[teamId]`)**:
    - Добавить таб **"Зарплаты"**.
    - Список участников с кнопками настройки их зарплат.
- [x] **Страница Проекта (`/.../projects/[projectId]`)**:
    - Добавить таб **"Выплаты"**.
    - Логика:
        - Если проект активен: кнопка "Рассчитать выплаты" → открывает Калькулятор.
        - Если завершен: показывает финальный отчет и историю.
- [ ] **Дашборд (`/dashboard`)**:
    - Добавить метрику "Ваша чистая прибыль" (сумма по всем закрытым проектам).
