## 🔍 Проблемы текущего ценообразования

### 1. Несогласованность курсов
- **LITE**: 61.25₽/$ (USD), 70.00₽/€ (EUR)
- **FOREMAN**: 61.875₽/$ (USD), 66.00₽/€ (EUR)
- **BRIGADE**: 79.60₽/$ (USD), 79.60₽/€ (EUR)

**Проблема:** Курсы валют различаются между планами, что создает несправедливость для пользователей.

### 2. Отклонение от реального курса
- **Текущий реальный курс (примерно):**
  - 1 USD ≈ 90-100₽
  - 1 EUR ≈ 100-110₽

- **Текущие цены используют курс:**
  - 1 USD ≈ 61-80₽ (занижен)
  - 1 EUR ≈ 66-80₽ (занижен)

**Проблема:** Цены в USD и EUR занижены относительно RUB, что может привести к потере прибыли.

### 3. Разные соотношения для разных планов
- BRIGADE имеет более высокий курс (79.60₽/$), чем LITE (61.25₽/$)
- Это создает несправедливость: пользователи BRIGADE платят относительно больше в рублях

## 💡 Методы выравнивания цен

### Метод 1: Фиксированный курс валют (Рекомендуется)

**Принцип:** Использовать единый курс валют для всех планов.

**Преимущества:**
- Справедливость для всех пользователей
- Простота расчета и поддержки
- Прозрачность ценообразования

**Реализация:**
1. Определить базовый курс (например, 1 USD = 95₽, 1 EUR = 105₽)
2. Рассчитать цены для всех планов по этому курсу
3. Округлить до удобных значений

**Пример расчета для LITE (490₽):**
- USD: 490₽ / 95₽ = $5.16 → округлить до **$5** или **$6**
- EUR: 490₽ / 105₽ = €4.67 → округлить до **€5**

**Новые цены (пример):**
| План | RUB | USD (курс 95₽/$) | EUR (курс 105₽/€) |
|------|-----|------------------|-------------------|
| LITE | 490₽ | $5 (475₽) | €5 (525₽) |
| FOREMAN | 990₽ | $10 (950₽) | €9 (945₽) |
| BRIGADE | 1990₽ | $21 (1995₽) | €19 (1995₽) |

---

### Метод 2: Динамический курс с API

**Принцип:** Использовать актуальный курс валют из внешнего API.

**Преимущества:**
- Всегда актуальные курсы
- Автоматическое обновление
- Справедливость для всех пользователей

**Недостатки:**
- Зависимость от внешнего сервиса
- Сложность реализации
- Возможны резкие скачки цен

**Реализация:**
1. Интегрировать API курсов валют (например, ExchangeRate-API, CurrencyAPI)
2. Обновлять курсы ежедневно или при изменении
3. Рассчитывать цены в реальном времени или кэшировать на день

**Примеры API:**
- ExchangeRate-API: https://www.exchangerate-api.com/
- CurrencyAPI: https://currencyapi.com/
- Центральный банк России: https://www.cbr.ru/development/sxml/

---

### Метод 3: Региональное ценообразование (Geographic Pricing)

**Принцип:** Разные цены для разных регионов с учетом покупательной способности.

**Преимущества:**
- Учет покупательной способности в разных странах
- Оптимизация выручки
- Справедливость для пользователей

**Недостатки:**
- Сложность управления
- Возможность арбитража (пользователи из разных регионов)

**Реализация:**
1. Определить регионы (Россия/СНГ, Европа, США/Канада)
2. Установить разные курсы для каждого региона
3. Определять регион по IP или выбору пользователя

**Пример:**
- **Россия/СНГ:** 1 USD = 95₽ (базовый курс)
- **Европа:** 1 EUR = 105₽ (немного выше)
- **США/Канада:** 1 USD = 100₽ (выше для компенсации)

---

### Метод 4: Округление до психологически привлекательных цен

**Принцип:** Использовать "магические" цены ($9.99, €9.99, 990₽).

**Преимущества:**
- Психологически привлекательные цены
- Улучшение конверсии
- Простота запоминания

**Недостатки:**
- Может не соответствовать точному курсу
- Требует компромиссов

**Реализация:**
1. Рассчитать цену по фиксированному курсу
2. Округлить до ближайшей "магической" цены
3. Проверить, что отклонение не превышает 5-10%

**Пример для FOREMAN (990₽):**
- По курсу 95₽/$: $10.42
- Округлить до: **$9.99** или **$10.99**
- Проверить: $9.99 × 95₽ = 949₽ (отклонение -4.1% ✅)

---

### Метод 5: Гибридный подход (Рекомендуется для продакшена)

**Принцип:** Комбинация фиксированного курса с периодическим обновлением.

**Преимущества:**
- Стабильность цен
- Возможность корректировки
- Справедливость

**Реализация:**
1. Установить фиксированный курс на квартал/полгода
2. Пересматривать цены раз в квартал
3. Уведомлять пользователей о изменениях за 30 дней

**Пример:**
- **Q1 2025:** 1 USD = 95₽, 1 EUR = 105₽
- **Q2 2025:** Пересмотр курсов (если изменение > 10%)
- **Grandfather pricing:** Существующие подписки сохраняют старую цену

## 📋 Рекомендации по выравниванию

### Краткосрочное решение (Немедленно)
1. **Выбрать единый курс** для всех планов:
   - 1 USD = 95₽ (или 100₽ для упрощения)
   - 1 EUR = 105₽ (или 110₽ для упрощения)

2. **Пересчитать все цены** по этому курсу

3. **Округлить** до удобных значений ($5, $10, $20, €5, €10, €20)

### Долгосрочное решение (3-6 месяцев)
1. **Внедрить API курсов валют** для автоматического обновления
2. **Установить правила пересмотра** (например, при изменении курса > 10%)
3. **Добавить grandfather pricing** для существующих подписок
