# 🚀 ProRab v0.5.0 - Release Notes

## 📅 Дата релиза: 2025-01-XX

## 🎯 Основные изменения

### 🔗 Система приглашений - Полная поддержка незарегистрированных пользователей

До версии 0.5.0 незарегистрированные пользователи не могли использовать ссылки-приглашения. Теперь это полностью поддерживается!

#### Что нового:

1. **Для незарегистрированных пользователей:**
   - ✅ Новая кнопка "Создать аккаунт и присоединиться"
   - ✅ Автоматический возврат после регистрации
   - ✅ Пропуск онбординга для приглашенных
   - ✅ Мгновенное присоединение к команде

2. **Улучшенная навигация:**
   - ✅ Параметр `redirect` в URL
   - ✅ Сохранение контекста между login ⟷ register
   - ✅ Автоматические переходы без лишних кликов

3. **Множественные команды:**
   - ✅ Пользователь может быть в нескольких командах
   - ✅ Можно быть владельцем + участником разных команд
   - ✅ Существующие членства сохраняются

### 🐛 Исправления ошибок

#### 1. Apollo Client Imports (Admin Panel)
- **Проблема:** Неправильные импорты `useMutation` из `@apollo/client`
- **Решение:** Изменено на `@apollo/client/react`
- **Затронуто:** 4 файла admin панели

#### 2. Projects Display Filter
- **Проблема:** Проекты исчезали при переключении фильтров
- **Решение:** Полностью переписана логика отображения
- **Улучшения:**
  - Упрощенная фильтрация
  - Удалены нестабильные анимации
  - Добавлен debug panel
  - Добавлены console.log для отладки

## 🎯 Сценарии использования

### Сценарий 1: Новый пользователь получает приглашение

```
1. Получает ссылку: /invite/ABC12345
2. Нажимает "Создать аккаунт и присоединиться"
3. Регистрируется
4. Автоматически возвращается на /invite/ABC12345
5. Автоматически присоединяется к команде
6. Попадает на страницу команды
```

**Время:** ~2 минуты
**Клики:** 3-4 (вместо 8-10 ранее)

### Сценарий 2: Владелец приглашает в свою команду

```
1. Владелец создает ссылку на 7 дней
2. Отправляет ссылку участнику
3. Участник переходит по ссылке
4. Участник регистрируется или логинится
5. Участник автоматически добавляется в команду
```

**Безопасность:**
- ✅ Одноразовая ссылка
- ✅ Ограниченный срок действия
- ✅ Валидация прав доступа

### Сценарий 3: Пользователь с командой принимает приглашение

```
До:
- Владелец: "Бригада Иванова"
- Участник: (нет)

Получает приглашение в "Строй Сервис"

После:
- Владелец: "Бригада Иванова" ✅
- Участник: "Строй Сервис" ✅
```

**Результат:** Пользователь видит обе команды, может переключаться между ними

```typescript
// ✅ Проверка существования кода
```
