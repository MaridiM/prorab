## 🎯 Обзор дизайн-системы

### Технологический стек

**Frontend Framework:**
- Next.js 16 (App Router)
- React 19
- TypeScript 5

**UI библиотеки:**
- **shadcn/ui** - основная компонентная библиотека
- **Tailwind CSS v4** - utility-first CSS фреймворк
- **Framer Motion** - библиотека анимаций
- **Radix UI** - примитивы для доступности (через shadcn/ui)
- **Lucide React** - иконки

**Дополнительные инструменты:**
- **class-variance-authority** - управление вариантами компонентов
- **clsx** + **tailwind-merge** - утилиты для классов
- **next-themes** - управление темами (light/dark)

### Архитектура дизайн-системы

Приложение использует **модульную компонентную архитектуру**:

```
apps/web/src/packages/components/
├── ui/              # Базовые UI компоненты (17 компонентов)
├── projects/        # Компоненты для проектов
├── expenses/        # Компоненты для расходов
├── financial/       # Финансовые дашборды
└── features/        # Функциональные компоненты
```

**Принципы:**
- ✅ Композиция через props
- ✅ Переиспользуемые примитивы
- ✅ Единая система токенов
- ✅ TypeScript-first подход

## ✨ Анимации и переходы

### Библиотека анимаций

**Framer Motion** используется для всех анимаций:

```typescript
import { motion, AnimatePresence, Variants } from 'framer-motion'
```

### Типы анимаций

#### 1. Fade In (Появление)

```typescript
const fadeIn: Variants = {
  hidden: { opacity: 0, y: 20 },
  visible: {
    opacity: 1,
    y: 0,
    transition: {
      duration: 0.5,
      ease: [0.22, 0.61, 0.36, 1] // Custom easing
    }
  }
}
```

**Использование:**
- Появление страниц
- Появление карточек
- Появление форм

#### 2. Stagger (Каскадное появление)

```typescript
const stagger = {
  hidden: {},
  visible: {
    transition: {
      staggerChildren: 0.1 // Задержка между элементами
    }
  }
}
```

**Использование:**
- Списки карточек
- Сетки элементов
- Дашборд с несколькими блоками

#### 3. Hover эффекты

**Поднятие карточки:**
```typescript
whileHover={{ y: -4, transition: { duration: 0.2 } }}
```

**Масштабирование:**
```typescript
whileHover={{ scale: 1.05 }}
```

**Поворот:**
```typescript
whileHover={{ scale: 1.05, rotate: 5 }}
```

#### 4. Кастомные анимации (CSS)

**Float (Плавание):**
```css
@keyframes float {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-20px); }
}
```

**Pulse Slow (Медленная пульсация):**
```css
@keyframes pulse-slow {
  0%, 100% { opacity: 1; }
  50% { opacity: 0.65; }
}
```

**Shimmer (Блеск):**
```css
@keyframes shimmer {
  0% { transform: translateX(-100%); }
  100% { transform: translateX(100%); }
}
```

### Переходы (Transitions)

**Универсальные переходы:**
```css
transition: 
  color 0.3s cubic-bezier(0.4, 0, 0.2, 1),
  background-color 0.3s cubic-bezier(0.4, 0, 0.2, 1),
  border-color 0.3s cubic-bezier(0.4, 0, 0.2, 1),
  box-shadow 0.3s cubic-bezier(0.4, 0, 0.2, 1),
  transform 0.3s cubic-bezier(0.4, 0, 0.2, 1),
  opacity 0.3s cubic-bezier(0.4, 0, 0.2, 1);
```

**Применяется к:**
- Кнопкам
- Карточкам
- Ссылкам
- Интерактивным элементам

### Easing функции

**Стандартная:**
- `cubic-bezier(0.4, 0, 0.2, 1)` - Material Design easing

**Кастомная (для анимаций):**
- `[0.22, 0.61, 0.36, 1]` - Более плавная, "bouncy" анимация

## 📱 Адаптивность

### Breakpoints (Tailwind CSS)

| Размер | Минимальная ширина | Использование |
|--------|-------------------|---------------|
| **Mobile** | 375px (default) | Базовый размер |
| **sm** | 640px | Планшеты (портрет) |
| **md** | 768px | Планшеты (альбом) |
| **lg** | 1024px | Ноутбуки |
| **xl** | 1280px | Десктопы |
| **2xl** | 1536px | Большие экраны |

### Mobile-First подход

Все стили начинаются с мобильной версии, затем добавляются медиа-запросы:

```tsx
// Пример адаптивной сетки
<div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6">
```

### Адаптивные паттерны

#### 1. Сетки

**Мобильный (1 колонка):**
```tsx
grid-cols-1
```

**Планшет (2 колонки):**
```tsx
md:grid-cols-2
```

**Десктоп (3 колонки):**
```tsx
lg:grid-cols-3
```

#### 2. Отступы

**Мобильный:**
```tsx
px-4 py-6
```

**Десктоп:**
```tsx
md:px-6 md:py-12
```

#### 3. Размеры шрифтов

**Мобильный:**
```tsx
text-xl
```

**Десктоп:**
```tsx
md:text-2xl lg:text-3xl
```

#### 4. Скрытие элементов

```tsx
hidden md:block  // Скрыто на мобильном, видно на планшете+
```

### Touch-friendly элементы

**Минимальные размеры:**
- Кнопки: минимум 44x44px (рекомендация Apple HIG)
- Интерактивные элементы: достаточный padding для удобного нажатия

**Пример:**
```tsx
className="h-12 px-4" // 48px высота, удобно для touch
```

useAutoValidateForm(form, ['email', 'password'])

- **Toast уведомления** - для успешных действий и ошибок

**Текущее состояние:**
- Success, Destructive, Warning

**Рекомендация:** Добавить:

#### Улучшить контрастность

**Проверить WCAG AA:**
- Соотношение контраста должно быть минимум 4.5:1 для текста
- 3:1 для крупного текста

### 3. Типографика

**Рекомендация:**

```css

```

**Рекомендация:** Добавить поддержку `prefers-reduced-motion`:
```css
@media (prefers-reduced-motion: reduce) {
  * {
    animation: none !important;
    transition: none !important;

}
```
