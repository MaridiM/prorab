# План реализации ProRab.space MVP

## Анализ требований

### Основные функции приложения:
1. **Учет расходов и прибыли** — главная боль прораба
2. **Фотоотчеты клиентам** — killer feature #1
3. **Расчет зарплаты бригаде** — killer feature #2
4. **Управление проектами (объектами)**
5. **Задачи (Kanban)**
6. **Управление командой**

### Роли пользователей:
- **Владелец (Прораб)** — полный доступ ко всем данным, финансам, настройкам
- **Участник бригады** — ограниченный доступ (не видит финансы, зарплаты, тариф)

### 4. Основное приложение (требует авторизации)

#### 4.1. Дашборд (главный экран)
**Путь:** `/dashboard`  
**Статус:** Не реализовано

**Данные для вывода:**
- **Хедер:**
  - Переключатель бригад (для участников) — Select/Dropdown
  - Иконка профиля → меню (Профиль, Настройки, Выход)
  - Текущая бригада (для владельца)

- **Список объектов:**
  - **Активные объекты** (сверху):
    - Карточка объекта:
      - Фото объекта (аватарка)
      - Название объекта
      - Адрес
      - Прогресс-бар (% готовности)
      - Прибыль объекта (зеленым/красным) — **только для владельца**
      - Бейдж непрочитанных реакций клиента (если есть)
  - **Архивные объекты** (снизу, свернуты по умолчанию):
    - Аналогичные карточки, но серым цветом
    - Кнопка "Развернуть архив"

- **FAB (Floating Action Button):**
  - Кнопка "+ Новый объект" (внизу справа, sticky)

**GraphQL запросы:**
- `myProjects(teamId: ID!)` — список проектов текущей бригады
- `myTeams` — список бригад пользователя (для переключателя)

---

#### 4.2. Страница объекта (детальная)
**Путь:** `/projects/[id]`  
**Статус:** Не реализовано

**Структура страницы (вкладки или блоки):**

**Вкладка 1: Инфо**
- **Основные данные:**
  - Название объекта (редактируемое)
  - Адрес (редактируемое)
  - Телефон клиента (редактируемое)
  - Сумма договора / Бюджет (редактируемое)
  - Дата начала → Дата сдачи (редактируемые)
  - Фото объекта (аватарка, редактируемое)
  - % готовности (слайдер, ручной или авто)
  - Заметки про объект (текстовое поле)

- **Финансовый виджет** (только для владельца):
  - Сумма договора: `X ₽`
  - Потрачено всего: `Y ₽` (красным)
  - Осталось в бюджете: `Z ₽` (зеленым)
  - Прибыль объекта: `W ₽ (N%)` (зеленым/красным)
  - Из них на зарплату бригаде: `V ₽`
  - Чистая прибыль прораба: `U ₽`
  - Круговая диаграмма расходов по категориям
  - Топ-5 самых дорогих статей расходов

- **Действия:**
  - Кнопка "В архив" (переводит объект в архив)
  - Кнопка "Закрыть объект и рассчитать зарплату" (только для владельца)

**Вкладка 2: Расходы**
- **FAB:** Кнопка "+ Расход" (sticky bottom)
- **Лента расходов:**
  - Хронологический список (новые сверху)
  - Карточка расхода:
    - Дата и время
    - Сумма (крупно)
    - Категория (бейдж)
    - Фото чека (1-5 фото, клик → lightbox)
    - Комментарий (если есть)
    - Флаг "Оплатил клиент" (если установлен)
  - Фильтр по категориям (выпадающий список)
  - Итоговая сумма расходов под лентой

**Вкладка 3: Задачи (Kanban)**
- **3 колонки:**
  - Запланировано
  - В работе
  - Готово
- **Карточка задачи:**
  - Название задачи
  - Исполнитель (аватарка + имя)
  - Дедлайн (если установлен)
  - Чек-лист (подзадачи)
  - Drag & Drop для перемещения между колонками
- **Кнопка "+ Новая задача"** (в колонке "Запланировано")

**Вкладка 4: Фотоотчеты**
- **Список созданных отчетов:**
  - Карточка отчета:
    - Дата создания
    - Количество фото
    - Комментарий (превью)
    - Ссылка на отчет (кнопка "Копировать ссылку")
    - Количество реакций клиента
- **Кнопка "+ Новый отчет клиенту"**

**GraphQL запросы:**
- `project(id: ID!)` — данные проекта
- `projectExpenses(projectId: ID!)` — список расходов
- `projectTasks(projectId: ID!)` — список задач
- `projectReports(projectId: ID!)` — список фотоотчетов

#### 4.3. Форма создания/редактирования объекта
**Путь:** `/projects/new` или `/projects/[id]/edit`  
**Статус:** Не реализовано

**Поля формы:**
- Название объекта * (обязательно)
- Адрес
- Телефон клиента
- Сумма договора (бюджет) * (обязательно)
- Дата начала
- Дата сдачи
- Фото объекта (загрузка файла)
- % готовности (слайдер, по умолчанию 0%)

**Валидация:**

- Проверка, что дата сдачи >= даты начала

**GraphQL мутации:**
- `createProject(input: CreateProjectInput!)`
- `updateProject(id: ID!, input: UpdateProjectInput!)`

#### 4.4. Форма добавления расхода
**Путь:** Модальное окно или отдельная страница `/projects/[id]/expenses/new`  
**Статус:** Не реализовано

**Поля формы:**
- Сумма * (обязательно, числовое поле с NumPad на мобильных)
- Категория * (обязательно, выпадающий список):
  - Материалы
  - Работа бригады
  - Черновые материалы
  - Чистовые материалы
  - Инструмент
  - Аренда техники
  - Транспорт
  - Прочее
  - + Добавить свою категорию
- Фото чека * (обязательно, минимум 1, максимум 5 фото)
  - Загрузка из галереи или камера
  - Превью загруженных фото
  - Возможность удалить фото
- Комментарий (необязательно, текстовое поле)
- Чекбокс "Оплатил клиент напрямую" (не вычитается из прибыли)

**UX требования:**
- Форма должна заполняться за 3-5 секунд
- Оптимизация для мобильных устройств
- Быстрая загрузка фото (сжатие на клиенте)

**GraphQL мутации:**
- `createExpense(input: CreateExpenseInput!)`

#### 4.7. Страница настройки оплаты участника
**Путь:** `/settings/team/members/[id]/payment`  
**Статус:** Не реализовано  
**Доступ:** Только для владельца

**Поля формы:**
- Фото участника (загрузка)
- Имя (редактируемое)
- Телефон (редактируемое)
- Тип оплаты (выбор одного):
  - % от прибыли объекта (например, 15%)
  - Фиксированная сумма за объект (например, 50 000 ₽)
  - Оплата за м² (сумма × площадь объекта)
  - Оплата за день (сумма × количество дней)
  - Оплата почасовая (сумма × количество часов)
- Значение ставки (числовое поле, зависит от типа оплаты)

**GraphQL мутации:**
- `updateMemberPaymentSettings(memberId: ID!, input: PaymentSettingsInput!)`

## Данные для GraphQL API

### Запросы (Queries):
- `me` — текущий пользователь
- `myTeams` — список бригад пользователя
- `myTeam` — текущая бригада
- `teamMembers(teamId: ID!)` — участники бригады
- `myProjects(teamId: ID!)` — проекты бригады
- `project(id: ID!)` — детали проекта
- `projectExpenses(projectId: ID!)` — расходы проекта
- `projectTasks(projectId: ID!)` — задачи проекта
- `projectReports(projectId: ID!)` — фотоотчеты проекта
- `photoReportBySlug(slug: String!)` — публичный отчет по slug
- `mySubscription` — текущая подписка

### Мутации (Mutations):
- `createTeam(input: CreateTeamInput!)` — создание бригады
- `updateTeam(input: UpdateTeamInput!)` — обновление бригады
- `inviteTeamMember(email: String!)` — приглашение участника
- `generateInviteLink(teamId: ID!)` — генерация ссылки-приглашения
- `acceptInvite(token: String!)` — принятие приглашения
- `removeTeamMember(memberId: ID!)` — удаление участника
- `updateMemberPaymentSettings(memberId: ID!, input: PaymentSettingsInput!)` — настройка оплаты
- `createProject(input: CreateProjectInput!)` — создание проекта
- `updateProject(id: ID!, input: UpdateProjectInput!)` — обновление проекта
- `archiveProject(id: ID!)` — архивация проекта
- `createExpense(input: CreateExpenseInput!)` — добавление расхода
- `createTask(input: CreateTaskInput!)` — создание задачи
- `updateTask(id: ID!, input: UpdateTaskInput!)` — обновление задачи
- `moveTask(id: ID!, status: TaskStatus!)` — перемещение задачи (drag & drop)
- `createPhotoReport(input: CreatePhotoReportInput!)` — создание фотоотчета
- `addReportReaction(photoId: ID!, type: ReactionType!)` — добавление реакции (публичный API)
- `calculateProjectSalary(projectId: ID!)` — расчет зарплаты
- `closeProject(projectId: ID!)` — закрытие проекта
- `createSubscription(planId: ID!, period: SubscriptionPeriod!)` — создание подписки
- `cancelSubscription` — отмена подписки
- `updateProfile(input: UpdateProfileInput!)` — обновление профиля
