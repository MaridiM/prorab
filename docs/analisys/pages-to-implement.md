### 🔴 КРИТИЧНЫЕ (MVP - основа продукта)

#### 1. Дашборд (главный экран)
**Путь:** `/dashboard`  
**Приоритет:** 🔴 КРИТИЧНЫЙ  
**Статус:** ❌ Не реализовано

**Описание:**
Главный экран приложения после онбординга. Показывает список всех объектов текущей бригады.

**Компоненты:**
- **Хедер:**
  - Переключатель бригад (Select/Dropdown) - только для участников
  - Иконка профиля → меню (Профиль, Настройки, Выход)
  - Название текущей бригады (для владельца)

- **Список объектов:**
  - **Активные объекты** (сверху):
    - Карточка объекта:
      - Фото объекта (аватарка, круглое)
      - Название объекта (крупно)
      - Адрес (мелким текстом)
      - Прогресс-бар (% готовности, цветной)
      - Прибыль объекта (зеленым/красным) - **только для владельца**
      - Бейдж непрочитанных реакций клиента (если есть)
      - Клик → переход на `/projects/[id]`
  - **Архивные объекты** (снизу, свернуты по умолчанию):
    - Аналогичные карточки, но серым цветом
    - Кнопка "Развернуть архив" / "Свернуть архив"
    - При клике на архивный объект → переход на `/projects/[id]`

- **FAB (Floating Action Button):**
  - Кнопка "+ Новый объект" (внизу справа, sticky)
  - Клик → переход на `/projects/new`

**GraphQL запросы:**
- `myProjects(teamId: ID!)` - список проектов текущей бригады
- `myTeams` - список бригад пользователя (для переключателя)

**Особенности:**
- Mobile-first дизайн
- Pull-to-refresh для обновления списка
- Empty state, если объектов нет
- Loading state (skeleton)

#### 2. Страница объекта (детальная)
**Путь:** `/projects/[id]`  
**Приоритет:** 🔴 КРИТИЧНЫЙ  
**Статус:** ❌ Не реализовано

**Описание:**
Центральный хаб работы с объектом. Вкладки или блоки с разной информацией.

**Структура (вкладки или блоки):**

**Вкладка 1: Инфо**
- **Основные данные** (редактируемые inline или через модалку):
  - Название объекта (крупно, редактируемое)
  - Адрес (редактируемое)
  - Телефон клиента (редактируемое, с кнопкой звонка)
  - Сумма договора / Бюджет (редактируемое, крупно)
  - Дата начала → Дата сдачи (редактируемые)
  - Фото объекта (аватарка, редактируемое, клик → загрузка нового)
  - % готовности (слайдер, ручной или авто)
  - Заметки про объект (текстовое поле, редактируемое)

- **Финансовый виджет** (только для владельца):
  - Сумма договора: `X ₽` (крупно)
  - Потрачено всего: `Y ₽` (красным, крупно)
  - Осталось в бюджете: `Z ₽` (зеленым, крупно)
  - Прибыль объекта: `W ₽ (N%)` (зеленым/красным, очень крупно)
  - Из них на зарплату бригаде: `V ₽`
  - Чистая прибыль прораба: `U ₽`
  - Круговая диаграмма расходов по категориям
  - Топ-5 самых дорогих статей расходов (список)

- **Действия:**
  - Кнопка "В архив" (переводит объект в архив)
  - Кнопка "Закрыть объект и рассчитать зарплату" (только для владельца)

**Вкладка 2: Расходы**
- **FAB:** Кнопка "+ Расход" (sticky bottom)
- **Лента расходов:**
  - Хронологический список (новые сверху)
  - Карточка расхода:
    - Дата и время (мелко)
    - Сумма (крупно, жирным)
    - Категория (бейдж, цветной)
    - Фото чека (1-5 фото, клик → lightbox с зумом)
    - Комментарий (если есть)
    - Флаг "Оплатил клиент" (если установлен, иконка)
    - Клик на карточку → модалка с деталями
  - Фильтр по категориям (выпадающий список, sticky top)
  - Итоговая сумма расходов под лентой (крупно, жирным)

**Вкладка 3: Задачи (Kanban)**
- **3 колонки:**
  - Запланировано
  - В работе
  - Готово
- **Карточка задачи:**
  - Название задачи (крупно)
  - Исполнитель (аватарка + имя)
  - Дедлайн (если установлен, цветной бейдж)
  - Чек-лист (подзадачи, с галочками)
  - Drag & Drop для перемещения между колонками
- **Кнопка "+ Новая задача"** (в колонке "Запланировано")

**Вкладка 4: Фотоотчеты**
- **Список созданных отчетов:**
  - Карточка отчета:
    - Дата создания
    - Количество фото (бейдж)
    - Комментарий (превью, обрезанный)
    - Ссылка на отчет (кнопка "Копировать ссылку")
    - Количество реакций клиента (бейдж)
    - Клик → модалка с деталями
- **Кнопка "+ Новый отчет клиенту"**

**GraphQL запросы:**
- `project(id: ID!)` - данные проекта
- `projectExpenses(projectId: ID!)` - список расходов
- `projectTasks(projectId: ID!)` - список задач
- `projectReports(projectId: ID!)` - список фотоотчетов

**Особенности:**
- Mobile-first дизайн
- Swipe между вкладками (на мобильных)
- Автосохранение изменений
- Loading states для каждой вкладки

#### 3. Форма создания объекта
**Путь:** `/projects/new`  
**Приоритет:** 🔴 КРИТИЧНЫЙ  
**Статус:** ❌ Не реализовано

**Описание:**
Форма для создания нового объекта (проекта).

**Поля формы:**
- Название объекта * (обязательно, текстовое поле)
- Адрес (текстовое поле)
- Телефон клиента (телефонное поле с маской)
- Сумма договора (бюджет) * (обязательно, числовое поле)
- Дата начала (date picker)
- Дата сдачи (date picker)
- Фото объекта (загрузка файла, превью)
- % готовности (слайдер, по умолчанию 0%)
- Заметки (текстовое поле, многострочное)

**Валидация:**
- Проверка лимита активных объектов (по тарифу)
- Проверка, что дата сдачи >= даты начала
- Минимум 2 символа в названии

**GraphQL мутации:**
- `createProject(input: CreateProjectInput!)`

**Особенности:**
- Mobile-first дизайн
- Автосохранение в draft (localStorage)
- Валидация в реальном времени
- Success toast после создания
- Редирект на `/projects/[id]` после создания

#### 5. Форма добавления расхода
**Путь:** Модальное окно (предпочтительно) или `/projects/[id]/expenses/new`  
**Приоритет:** 🔴 КРИТИЧНЫЙ  
**Статус:** ❌ Не реализовано

**Описание:**
Самая часто используемая форма. Должна заполняться за 3-5 секунд.

**Поля формы:**
- Сумма * (обязательно, числовое поле с NumPad на мобильных)
- Категория * (обязательно, выпадающий список):
  - Материалы
  - Работа бригады
  - Черновые материалы
  - Чистовые материалы
  - Инструмент
  - Аренда техники
  - Транспорт
  - Прочее
  - + Добавить свою категорию (модалка)
- Фото чека * (обязательно, минимум 1, максимум 5 фото):
  - Загрузка из галереи или камера
  - Превью загруженных фото (сетка)
  - Возможность удалить фото (крестик)
  - Сжатие на клиенте перед отправкой
- Комментарий (необязательно, текстовое поле)
- Чекбокс "Оплатил клиент напрямую" (не вычитается из прибыли)

**UX требования:**
- Форма должна заполняться за 3-5 секунд
- Оптимизация для мобильных устройств
- Быстрая загрузка фото (сжатие на клиенте)
- NumPad для суммы на мобильных
- Автофокус на поле "Сумма"

**GraphQL мутации:**
- `createExpense(input: CreateExpenseInput!)`

**Особенности:**
- Модальное окно (предпочтительно) для быстрого доступа
- Success toast после создания
- Автоматическое обновление списка расходов
- Закрытие модалки после успешного создания

- Название объекта (крупно)
- Дата отчета (мелко)
- Прогресс-бар готовности объекта (%) (цветной, крупно)
- Галерея фотографий (1-20 фото):
  - Сетка или карусель
  - Клик → fullscreen с зумом
  - Swipe для переключения
- Комментарий прораба (текст, крупно)
- Кнопки реакций на каждое фото (❤️ ✅ ❓):
  - Клик → сохранение реакции
  - Подсчет реакций
  - Отображение активной реакции
- Кнопка "Написать прорабу" (WhatsApp/Telegram deep links):
  - Открывает мессенджер с готовым текстом

**Особенности:**
- Read-only доступ (без авторизации)
- Адаптивный дизайн (mobile-first)
- Реакции сохраняются в БД и отображаются у прораба
- Ссылка работает вечно
- SEO-оптимизация (meta tags)

**GraphQL запросы:**
- `photoReportBySlug(slug: String!)` - получение отчета по slug
- `addReportReaction(photoId: ID!, type: ReactionType!)` - добавление реакции (публичный API)

**Статус:** ❌ Не реализовано

  - Имя участника (крупно)
  - Тип оплаты (мелко)
  - Рассчитанная сумма (крупно, жирным)
  - Формула расчета (для прозрачности, мелко):
    - "15% от прибыли 905 000 ₽ = 135 750 ₽"
    - "50 000 ₽ × 1 объект = 50 000 ₽"
    - и т.д.

  - Итого на бригаду: `X ₽` (крупно, жирным)

    ```
    Объект "Название" закрыт
    
    Вася — плитка: 87 400 ₽
    Петя — штукатурка: 74 200 ₽
    ...
    
    Итого на бригаду: 283 500 ₽
    Моя прибыль: 361 500 ₽
    ```
  - Копирует в буфер обмена
  - Открывает WhatsApp с готовым текстом
- Кнопка "Закрыть объект" (фиксирует расчеты, переводит объект в архив)

**GraphQL мутации:**
- `calculateProjectSalary(projectId: ID!)` - предварительный расчет
- `closeProject(projectId: ID!)` - финальное закрытие

**Особенности:**
- Подтверждение перед закрытием
- Success toast после закрытия
- Редирект на дашборд после закрытия

#### 11. Страница тарифов
**Путь:** `/pricing` или `/settings/pricing`  
**Приоритет:** 🟡 ВАЖНЫЙ  
**Статус:** ❌ Не реализовано

**Описание:**
Выбор тарифа и управление подпиской.

**Данные для вывода:**
- **3 тарифных плана:**
  - Лайт (490 ₽/мес):
    - 1 активный объект
    - 1 участник (только прораб)
    - Учёт расходов
    - Фотоотчёты
  - Прораб (990 ₽/мес или 7 900 ₽/год):
    - До 4 активных объектов
    - До 3 участников
    - Расчёт зарплаты
    - Все функции
  - Бригада (1 990 ₽/мес или 12 900 ₽/год):
    - Безлимит объектов
    - До 10 участников
    - Полный контроль
    - Приоритетная поддержка

## 📝 Примечания

1. **Модальные окна vs отдельные страницы:**
   - Формы добавления расхода и создания фотоотчета - лучше модалки (быстрый доступ)
   - Формы создания/редактирования объекта - отдельные страницы (больше полей)
   - Расчет зарплаты - можно модалку (быстрый доступ)

2. **Mobile-first:**
   - Все страницы должны быть оптимизированы для мобильных устройств
   - Swipe жесты для навигации
   - Sticky кнопки для быстрого доступа

3. **GraphQL интеграция:**
   - Все страницы должны использовать GraphQL запросы/мутации
   - Кэширование запросов через Apollo Client
   - Оптимистичные обновления UI

4. **Валидация:**
   - Все формы должны использовать `react-hook-form` + `zod`
   - Валидация на клиенте и сервере
   - Понятные сообщения об ошибках

5. **Loading states:**
   - Skeleton loaders для всех списков
   - Spinner для форм
   - Empty states для пустых списков
