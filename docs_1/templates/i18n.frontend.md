# Frontend i18n (Next.js + next-intl)

- Библиотека: `next-intl` (App Router).
- Локали: `apps/web/src/packages/libs/i18n/locales/{en,ru}/core.json` + модульные (`apps/web/src/modules/auth/shared/libs/i18n/locales`, `apps/web/src/modules/organization/shared/libs/i18n/locales`).
- Язык хранится в cookie `language`; доступные языки: `en`, `ru` (`apps/web/src/packages/libs/i18n/config.ts`).
- Плагины Next: `next.config.ts` оборачивается `createNextIntlPlugin('./src/packages/libs/i18n/request.ts')`.

## Конфигурация

- Request config: `apps/web/src/packages/libs/i18n/request.ts`
  - Определяет `locale` из cookie через `getCurrentLanguage()` (server action).
  - Собирает словари: `{ ...translations[locale], ...authTranslations[locale] }` (при необходимости добавляйте другие модули).
- Типы и ключи:
  - `apps/web/src/packages/libs/i18n/types/typed.ts` — объединяет `TTranslations`, `TAuthTranslationsKeys`, `TOrganizationTranslationsKeys`, экспортирует типизированные `useTranslations`/`getTranslations`.
  - `apps/web/src/packages/libs/i18n/types/paths.ts` — утилиты PathKeys/GetByPath/TypedT для подсказок ключей.
- Язык:
  - `getCurrentLanguage` / `setLanguage` (`apps/web/src/packages/libs/i18n/language.ts`) работают с cookie на сервере (`'use server'`).
- Провайдер:
  - `apps/web/src/app/layout.tsx` — встраивает `NextIntlClientProvider` с `messages` и `locale` из `getMessages`/`getLocale`, вокруг всего приложения.

## Шаблоны использования

### 1) Server Component
```tsx
// apps/web/src/app/(root)/auth/page.tsx
import { getTranslations } from '@/packages/libs/i18n'

export default async function Page() {
  const t = await getTranslations('auth')
  return <h1>{t('login.title')}</h1>
}
```

### 2) Client Component
```tsx
// apps/web/src/modules/auth/widgets/auth-form.tsx
'use client'
import { useTranslations } from '@/packages/libs/i18n'

export const AuthForm = () => {
  const t = useTranslations('auth.login')
  return <span>{t('form.signIn')}</span>
}
```

### 3) Переключатель языка (server action)
```tsx
// apps/web/src/packages/components/features/appearence/change-language.tsx
'use client'
import { languages, setLanguage } from '@/packages/libs/i18n'

async function onChange(lang: string) {
  'use server'
  await setLanguage(lang as typeof languages[number])
}
```

### 4) Добавление модульных переводов
1. Создайте `locales/{en,ru}/<ns>.json` в модуле (например, `apps/web/src/modules/organization/shared/libs/i18n/locales`).
2. Экспортируйте в `locales/index.ts` и реэкспортируйте в `i18n.types.ts`.
3. Добавьте словари в `apps/web/src/packages/libs/i18n/request.ts` (spread в `messages`).
4. Используйте `useTranslations('<ns>')` или `getTranslations('<ns>')`.

## Проверочный чек-лист
- `next.config.ts` использует `createNextIntlPlugin('./src/packages/libs/i18n/request.ts')`.
- Cookie `language` читается/пишется только через `getCurrentLanguage`/`setLanguage`.
- Все словари подключены в `request.ts`; при добавлении нового модуля обновите merge.
- Типы ключей подтягиваются из `typed.ts`; IDE подсказывает валидные ключи.
