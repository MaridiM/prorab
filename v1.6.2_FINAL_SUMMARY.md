## ✨ New Features

### 1. Automatic Payment Provider Selection

**IP-based geolocation determines provider:**

- 🇷🇺 Russia, Belarus, Kazakhstan → **Yookassa** (Primary)
- 🇪🇺 Europe, Ukraine, USA → **Stripe** (Secondary)
- 🏠 Localhost → **Stripe** (Default)

**How it works:**

```typescript
// Extract IP from request
const ip = getRealIP(context.req)

// Auto-select provider
const provider = getProviderByIP(ip)
// → YOOKASSA or STRIPE

// Initialize payment with selected provider
await paymentsService.initializePayment(subscriptionId, userId, provider, ip)
```

### 2. Development Mode Mock Payments 🧪

**Test subscription flow WITHOUT real payment credentials!**

**When you don't have `STRIPE_SECRET_KEY` or `YOOKASSA_SHOP_ID` configured:**

- System automatically enters mock mode (development only)
- Returns fake payment data
- Redirects to: `?mock=true&provider=stripe&amount=990`
- Logs show: `🧪 Stripe MOCK: Creating fake payment session`

**Production mode:**

- Requires real credentials
- Throws error if missing
- No mock implementations available

**Benefits:**

- ✅ Test full UI flow without payment gateway setup
- ✅ No credit card needed
- ✅ Safe for development
- ✅ Automatic switch to production when credentials added

## 📝 Technical Details

### Provider Initialization Pattern

**Before (broken):**

```typescript
constructor() {
  this.initializeClient() // ❌ Async in constructor!
}

private async initializeClient() {
  this.secretKey = await this.systemSettings.getValue('key')
  // Never executed properly!
}
```

**After (fixed):**

```typescript
constructor() {
  this.initializeClient() // ✅ Synchronous - loads from env
}

private initializeClient() {
  this.secretKey = this.configService.get('STRIPE_SECRET_KEY')
  // Immediate execution!
}

private async ensureInitialized() {
  if (this.client) return // Already initialized

  // Lazy load from SystemSettings if needed
  this.secretKey = await this.systemSettings.getValue('key')

  if (!this.secretKey && isDevelopment) {
    // Mock mode!
    return
  }
}

async createPayment(params) {
  await this.ensureInitialized()

  if (!this.client) {
    // Return mock data in development
    return { paymentId: 'mock_...', ... }
  }

  // Real payment processing
}
```

### Geolocation Logic

```typescript
import * as geoip from 'geoip-lite'

const YOOKASSA_COUNTRIES = ['RU', 'BY', 'KZ', 'AM', 'AZ', 'GE', 'KG', 'MD', 'TJ', 'TM', 'UZ']

export function getProviderByIP(ip: string): PaymentProviderType {
  // Localhost → Stripe
  if (!ip || ip === '::1' || ip === '127.0.0.1') {
    return PaymentProviderType.STRIPE
  }

  // Get country from IP
  const geo = geoip.lookup(ip)
  if (!geo || !geo.country) {
    return PaymentProviderType.STRIPE // Default
  }

  // CIS → Yookassa
  if (YOOKASSA_COUNTRIES.includes(geo.country)) {
    return PaymentProviderType.YOOKASSA
  }

  // Rest of world → Stripe
  return PaymentProviderType.STRIPE
}
```

## 🆘 Troubleshooting

### Error: "Не удалось определить команду"

**Solution:** Create a team first:

```
Navigate to Teams → Click "Создать команду"
```

### Error: "Subscription already exists"

**Solution:** Clean up duplicates:

```bash
cd apps/api
psql -h localhost -p 54320 -U prorab -d prorab -f prisma/cleanup-duplicate-subscriptions.sql
```

Password: `prorab`

### Error: "ECONNREFUSED" database

**Solution:** Start PostgreSQL:

```bash
docker compose up -d postgres
# Wait 10 seconds
cd apps/api && pnpm dev
```

### Mock mode not working

**Check:**

1. No `STRIPE_SECRET_KEY` in `.env`
2. `NODE_ENV !== 'production'`
3. API server was restarted

**Fix:** Remove credentials temporarily and restart API.
